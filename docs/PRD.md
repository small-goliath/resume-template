# 개인 포트폴리오/이력서 웹사이트 MVP PRD

## 🎯 핵심 정보

**목적**: 개발자의 경력, 역량, 프로젝트를 체계적으로 보여주는 원스톱 포트폴리오 웹사이트 구축
**사용자**: 자신의 경력과 포트폴리오를 효과적으로 전시하고자 하는 개발자 및 이를 열람하는 채용담당자/동료

## 🚶 사용자 여정

```
1. [랜딩 페이지/메인 포트폴리오 페이지]
   ↓ 자동 로딩

2. [프로필 영역 표시]
   - 성명, MBTI, 프로필 이미지
   - 외부 링크: Github, 블로그, 경력기술서
   - 24시간 시계 확인 → 실시간 시간 및 현재 루틴 파악
   ↓

3. [섹션 선택 (탭/아코디언)]
   ↓

   [타임라인] → 시간순 경력 보기 → [이벤트 상세]
   [교육사항] → 교육 이력 보기
   [역량] → 기술 스택 키워드 확인
   [동료평가] → 이미지 리스트 보기 → [확대/축소 모드]
   [사이드프로젝트] → 프로젝트 링크 클릭 → [새창 이동]
   [수상] → 상장 이미지 확인 → [링크 클릭 시 새창]
   [인턴십] → 인턴 경험 보기
   [연구활동] → 연구 정보 보기 → [링크/문서 새창]
   [봉사활동] → 봉사 이력 보기
   [대/외활동] → 활동 이력 보기
   ↓

4. [완료] → 각 섹션을 자유롭게 탐색
```

## 🛠️ 기술 스택 (최신 버전)

### 🎨 프론트엔드 프레임워크

- **Next.js 16** (App Router) - React 풀스택 프레임워크
- **TypeScript 5.6+** - 타입 안전성 보장
- **React 19** - UI 라이브러리 (최신 동시성 기능)

### 🎨 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 새로운 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** - 고품질 React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리

### 🔧 백엔드 프레임워크

- **Python 3.12+** - 백엔드 언어
- **FastAPI 0.115+** - 고성능 비동기 웹 프레임워크
- **Uvicorn** - ASGI 서버

### 🗄️ 데이터베이스 & ORM

- **Supabase** - BaaS (PostgreSQL 호스팅 제공)
- **PostgreSQL 16+** - 관계형 데이터베이스
- **psycopg2** 또는 **asyncpg** - PostgreSQL 어댑터

### 🚀 배포 & 호스팅

- **Vercel** - Next.js 16 최적화 배포 플랫폼
- **Vercel Serverless Functions** - FastAPI 배포 (Python Runtime)

### 🔄 개발 환경

- **npm** - 의존성 관리
- **concurrently** - 로컬 개발 시 Next.js + FastAPI 동시 실행

### 📦 주요 라이브러리

- **axios** 또는 **fetch** - API 통신
- **swr** 또는 **react-query** - 서버 상태 관리
- **yet-another-react-lightbox** - 이미지 갤러리/확대 기능

### Phase 1: 데이터베이스 & API 기반 구축

1. Supabase PostgreSQL 스키마 생성 (`docs/database/schema.sql`)
2. Seed 데이터 생성 (`docs/database/seed.sql`)
3. FastAPI 엔드포인트 개발 (GET /api/profile, /api/timeline, /api/education 등)
4. 로컬 개발 환경 설정 (npm run dev → Next.js + FastAPI 동시 실행)

### Phase 2: 프론트엔드 핵심 기능

1. 프로필 영역 (F001)
2. 섹션 선택 UI (F023 - 탭/아코디언)
3. 타임라인 (F002)
4. 교육사항 (F003)
5. 역량 (F004)

### Phase 2.5: 24시간 루틴 시계

1. Supabase `daily_routine` 테이블 생성
2. Seed 데이터 추가 (기본 루틴 7개)
3. FastAPI 엔드포인트 개발
   - GET /api/daily-routine (조회)
   - POST /api/daily-routine (생성, 관리자 인증)
   - PUT /api/daily-routine/{routine_id} (수정, 관리자 인증)
   - DELETE /api/daily-routine/{routine_id} (삭제, 관리자 인증)
4. DailyRoutineClock 컴포넌트 개발
   - SVG 24시간 시계 렌더링
   - KST 기준 시침/분침 회전 애니메이션
   - 시간대별 호(Arc) 렌더링 (DB 데이터 기반)
   - 범례 컴포넌트
   - 중앙 "small-goliath" 텍스트
5. Profile 섹션에 시계 통합
6. 반응형 디자인 적용 (모바일 280px, 데스크톱 400px)

### Phase 3: 추가 섹션 구현

1. 동료평가 갤러리 (F005 - 이미지 확대/축소 포함)
2. 사이드프로젝트 (F006)
3. 수상 (F007)
4. 인턴십 (F008)
5. 연구활동 (F009)
6. 봉사활동 (F010)
7. 대/외활동 (F011)

### Phase 4: 배포 & 최적화

1. Vercel 배포 설정
2. 환경 변수 설정 (SUPABASE_URL, SUPABASE_KEY)
3. 이미지 최적화 (Next.js Image 컴포넌트)
4. SEO 메타데이터 설정

### Phase 4.5: 루틴 관리 기능

1. `/admin/daily-routine` 페이지 생성
2. 루틴 목록 표시 (테이블 뷰, sort_order 정렬)
3. 루틴 생성 폼
   - 시간대 입력 (start_hour, end_hour)
   - 라벨 텍스트 입력
   - 색상 선택 드롭다운 (5가지 네온 색상)
   - 글로우 강도 선택 (dim/medium/bright)
4. 루틴 수정/삭제 기능
5. 시간대 충돌 검증 (클라이언트 사이드)
6. 정렬 순서 조정 (Drag & Drop 또는 숫자 입력)

## 🚀 시작 가이드

### 로컬 개발 환경 실행

```bash
# 1. 의존성 설치
npm install

# 2. 환경 변수 설정 (.env.local)
NEXT_PUBLIC_API_URL=http://localhost:8000
SUPABASE_URL=your-supabase-url
SUPABASE_KEY=your-supabase-key

# 3. 개발 서버 실행 (Next.js + FastAPI 동시 실행)
npm run dev
```

### Vercel 배포

```bash
# 1. Vercel CLI 설치
npm i -g vercel

# 2. 프로젝트 배포
vercel

# 3. 환경 변수 설정 (Vercel Dashboard)
SUPABASE_URL=your-supabase-url
SUPABASE_KEY=your-supabase-key
```
